# UpClaw v0.3.0 外置工具适配层设计文档

日期：2026-09-02
状态：已实现（待提交）

## 背景与目标

UpClaw v0.2.0 已具备 23 项内置检测模块（零第三方依赖、证据级反幻觉）。
用户的核心诉求：把本机已装载的「一批渗透工具」（Yakit、Burp、ZAP、AppScan、ARL、BeEF、
nuclei 等）的能力接入 UpClaw，使扫描更全面、准确率更高。

经确认采用**外部工具适配层**方案（而非把商业工具源码克隆进仓库，后者存在许可与体积问题）：

1. 自动检测本机已安装的工具（`shutil.which`），扫描时自动调用；
2. 各工具输出归一化为 UpClaw Finding（沿用证据优先/拒绝幻觉约定）；
3. 未安装工具自动跳过，核心零依赖架构不变；
4. GUI/API 类工具（Yakit/BeEF/Burp/AppScan/ARL）仅识别并提示人工驱动方式。

明确**不在本次范围**：将商业工具（Burp/AppScan）二进制或源码打包进仓库；
把外部工具编译产物克隆进仓库；内置各工具的完整复刻（工作量和体积不可控）。

## 架构

保持单文件结构。新增 `UPCLAW-V0.3-EXT-TOOLS` 段，位于 `AVAILABLE` 注册表之后：

```python
def _ext_run_<name>(store: FindingStore, url: str, cfg: dict[str, Any]) -> bool | None:
    ...
```

返回值约定：`None`=未安装/不可用，`False`=条件不满足跳过，`True`=已执行。

- 注册表：`EXT_TOOL_RUN`（可自动执行，顺序即执行顺序）+ `EXT_TOOL_LIST`（检测展示元数据，14 项）
- 辅助函数：`_bin_path` / `_run_bin`（列表参数执行，禁 shell）/ `_find_wordlist` / `_add_finding`
- 外部工具同时注册进 `AVAILABLE`（支持 `-c nuclei` 单独调用）；默认 `--checks` 不含它们，
  由扫描中的外部工具阶段自动启用
- 扫描阶段：`cmd_scan` 在内置模块之后调用 `run_external_phase(store, url, cfg, args)`

## 新增能力清单

### 可自动执行（9 项，detect → run → 归一化到报告）

| 工具 | 输出解析 | 证据口径 |
|------|----------|----------|
| nuclei | JSONL（-jsonl -silent） | VERIFIED，含 matcher 与 CVE 引用 |
| nmap | XML（-oX -），端口/服务/版本 | VERIFIED（INFO·recon） |
| sqlmap | stdout 特征（injectable/vulnerable/UNION） | VERIFIED；需 URL 带参数 |
| nikto | "- " 行启发式，OSVDB | UNVERIFIED（人工复核） |
| ffuf | JSON results（-ac 自动校准） | UNVERIFIED；需字典 |
| dirsearch | JSON results | UNVERIFIED |
| subfinder | stdout 子域列表 | VERIFIED（INFO·资产） |
| httpx | JSONL（url/status/title/tech） | VERIFIED（INFO·存活） |
| OWASP ZAP | zap-baseline.py -J JSON alerts | VERIFIED |

### 检测/提示（5 项，GUI/API 类）

Yakit、BeEF、Burp Suite、AppScan、ARL：`tools`/`doctor` 展示检测状态，提示按官方文档人工/API 驱动。

## CLI 变更

- 新增子命令 `upclaw tools`：列出 14 项工具检测结果
- `scan` 新增 `--no-ext`（关闭外部阶段）与 `--ext-tools nuclei,sqlmap`（白名单）
- `doctor` 增加外部工具检测状态区
- 版本号升至 `0.3.0`

## 配置项（config.json，可选）

`wordlist`（ffuf 字典）、`ext_nmap_ports`、`ext_*_timeout` 系列（默认 90~600s）。

## 合规说明

外部工具按其各自开源/商业许可独立分发，UpClaw 仅作驱动与结果归一化；
新增工具调用仍受既有授权门禁约束，仅用于已获书面授权的目标。
