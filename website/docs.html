1. 安装部署

环境要求

  • Python 3.10 或更高版本
  • 操作系统：Linux（推荐）、macOS、Windows（WSL2 推荐）
  • 可选：Kali Linux / Parrot OS 等渗透测试发行版，可直接使用内置工具链
  • 内存：≥ 4 GB；如需本地模型推理则建议 ≥ 16 GB

使用 pip 安装

pip install upclaw

# 验证安装
upclaw --version
# 输出：upclaw 1.0.0

从源码安装（开发版）

git clone <你的仓库地址> upclaw
cd upclaw
pip install -e .

2. 模型配置

UpClaw 本身不提供大模型，需要你接入自己的模型服务。首次运行会引导生成配置文件 ~/.upclaw/config.yaml。

交互式配置

upclaw init

手动配置示例

provider: openai-compatible
base_url: "https://your-endpoint/v1"
api_key: "sk-xxxxxxxx"
model: "your-model-name"
temperature: 0.2
max_tokens: 8192

# 代理（可选）
proxy: "http://127.0.0.1:7890"
隐私提示：AI 推理会将你主动提交的内容发送给所选模型服务商。处理敏感数据时请优先脱敏，企业版可使用私有化部署 + 内网模型，实现完全离线。详见《隐私政策》。

3. 基本用法

下达自然语言目标

upclaw "对 https://target.example.com 发起授权渗透，重点检查认证与上传功能"

指定范围与限制

# 限制最大步数与时间预算
upclaw "评估 192.168.1.0/24 的 Web 服务" --max-steps 30 --timeout 20m

# 只读模式：仅信息收集，不做利用验证
upclaw "信息收集 target.example.com" --mode recon

# 指定启用哪些技能
upclaw "检查 SQL 注入" --skills sqli,xss,idor

常用参数

参数说明示例
--max-steps最大推理/执行步数--max-steps 30
--timeout任务总超时--timeout 20m
--moderecon（侦察）/ full（全流程）--mode recon
--skills限定启用的渗透技能--skills sqli
--output报告输出目录--output ./reports
--format报告格式：md / html / json--format html
--verbose输出详细推理过程--verbose

4. 自主渗透工作流

UpClaw 采用 Reason → Explore → Fact → Reflect → Report 五阶段闭环，每一阶段都要求产出可验证的证据，避免大模型"幻觉式"报漏洞。

  • Reason（推理）：基于目标信息生成攻击面假设，并排出优先级。
  • Explore（探索）：调用工具链（nmap、指纹识别、目录爆破、POC 验证等）执行假设。
  • Fact（取证）：对每一步结果做事实核对，只保留有实证输出（响应报文、回显、截图）的发现。
  • Reflect（反思）：评估当前进展，判断是否需要调整假设、升级手法或收敛。
  • Report（报告）：汇总证据链，输出可直接交付的漏洞报告。
证据级反幻觉：任何未被实证支持的"疑似漏洞"都会被标记为 UNVERIFIED，不会进入最终报告正文。这一点对交付给客户的商业报告尤为重要。

5. MCP 工具链

UpClaw 通过 MCP（Model Context Protocol）接入外部安全工具，工具可插拔。已内置的典型能力包括：

  • 信息收集：端口扫描、服务指纹、子域名与资产发现、目录枚举
  • Web 应用：SQL 注入、XSS、SSRF、IDOR、文件上传、反序列化等检测
  • 认证与会话：弱口令、JWT 缺陷、会话固定、越权测试
  • 主机与内网：本地信息收集、权限配置核查、横向移动路径分析
  • 报告：证据归档、漏洞定级（CVSS）、修复建议生成
# 查看已加载的 MCP 工具
upclaw tools list

# 单独调用某个工具
upclaw tools run nmap --target 192.168.1.10

6. 报告与证据

任务结束后，UpClaw 会在输出目录生成结构化结果：

reports/
├── report.html          # 可视化报告（可交付客户）
├── report.md            # Markdown 报告
├── findings.json        # 结构化漏洞数据
└── evidence/            # 原始证据（请求/响应、截图）
    ├── finding-01/
    └── finding-02/
商业交付：专业版与企业版可去除 UpClaw 品牌标识，输出白标报告直接交付给你的客户。个人版报告带有产品水印。

7. 激活商业授权

购买专业版或企业版后，你会收到授权凭证（License Key），激活方式：

upclaw activate <YOUR-LICENSE-KEY>

# 查看授权状态
upclaw license info
  • 一个席位对应一台设备；更换设备前请先执行 upclaw license release 释放。
  • 企业版请联系管理员在团队后台分配席位。
  • 授权校验仅在激活与定期校验时联网，不影响离线使用。

8. 常见问题

提示模型调用失败 / 连接超时？

请检查 base_url、api_key 是否正确，以及是否需要配置代理（proxy）。可用 upclaw doctor 一键自检网络与配置。

扫描速度很慢？

默认策略偏保守以避免对目标造成影响。可通过 --max-steps 限制步数、--timeout 设置预算，或用 --skills 聚焦特定漏洞类型。

报告里为什么没有我预期中的漏洞？

UpClaw 只输出有实证证据的发现，未经验证的会归入"待人工复核"。这可能是目标确实不存在该漏洞，也可能是需要人工介入构造更复杂的利用链。建议结合手动测试交叉验证。

可以离线使用吗？

企业版支持私有化部署与内网离线运行（配合本地模型）。在线模式下的 AI 推理需要访问模型服务。
