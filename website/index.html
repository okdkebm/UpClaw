快速开始

四步安装，立即发起你的第一次 AI 渗透。

安装使用 pip 安装 UpClaw CLI。
配置 Key写入你的 LLM API Key。
启动进入交互式 REPL。
渗透用自然语言描述目标即可。
$ pip install upclaw
$ upclaw config set llm.api_key sk-xxx
$ upclaw
🦞 对 target.com 进行渗透测试
# 完整工作流（以 MiniMax 为例）
$ upclaw config set llm.base_url https://api.minimaxi.com/v1
$ upclaw config set llm.model MiniMax-M3
$ upclaw config set llm.api_key sk-your-key-here
$ upclaw doctor   # 检查环境
# Docker 一键部署
$ cp .env.example .env   # 填入 API Key
$ docker compose up --build
# 打开 http://127.0.0.1:7788
